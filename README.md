## 📌 Project Description

**S_Mart** is a full-stack e-commerce web application developed using Spring Boot and JSP, designed to provide a smooth and secure online shopping experience. The system enables users to register, log in, browse products, and manage their shopping cart efficiently.

The application implements role-based authentication using Spring Security, ensuring secure access for both users and administrators. Admins can manage products, monitor user activities, and control system operations through a dedicated dashboard.

The backend is built using Spring Boot with Hibernate (JPA) for ORM, enabling efficient database interaction with MySQL. The project follows a layered architecture (Controller, Service, Repository), promoting clean code structure and scalability.

### 🔑 Key Highlights

* Secure authentication and authorization using Spring Security
* Password encryption using BCrypt for enhanced security
* Dynamic product listing and cart management system
* Role-based access control (User/Admin)
* Integration of email services for notifications
* MVC architecture for better separation of concerns
* Scalable and maintainable backend design

## 🛠️ Tech Stack

* **Backend:** Java, Spring Boot
* **Frontend:** JSP, HTML, CSS
* **Database:** MySQL
* **ORM:** Hibernate (JPA)
* **Security:** Spring Security
* **Build Tool:** Maven
* **Server:** Apache Tomcat
